# One-Line Office Joke: 24-Hour Sprint

Entry for the [One-Line Office Joke: 24-Hour Sprint](https://make.fun/bounty/u-pucuys-one-line-office-joke-24-hour-sprint-aaf86162?ref=41fw6r6c) competition on [make.fun](https://make.fun/r/41fw6r6c).

## Run

Requires Node.js 22.18+ (no dependencies):

```bash
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```

In the `program/v1` grading sandbox, `main.ts` deterministically writes the validated single-line UTF-8 entry (1–200 characters, no trailing newline) to `/output/entry.txt`.
